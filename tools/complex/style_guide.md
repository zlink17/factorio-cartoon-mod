# Guide de style cartoon

À garder identique pour tous les sprites afin de conserver la cohérence.

## Règles visuelles

- Contours noirs épais et réguliers
- Aplats de couleurs vives, pas de dégradés complexes
- Ombrage simple (une teinte plus foncée par zone)
- Même point de vue et mêmes proportions que le sprite original
- Fond uni vert vif (#00FF00), sans ombre portée, pour faciliter le détourage

## Prompt type (à adapter)

> Redessine ce sprite de jeu en style cartoon : contours noirs épais, couleurs vives en aplats,
> ombrage simple. Garde exactement la même forme, la même perspective et les mêmes proportions
> que l'image fournie. Utilise la planche de référence jointe pour le style.
> Fond uni vert (#00FF00), aucun texte, aucune ombre portée.

## Planche de référence

Ajouter ici le fichier choisi une fois le style validé : `tools/complex/reference_sheet.png`.
