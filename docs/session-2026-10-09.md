## Objectif

Mod Factorio 2.0 qui passe toutes les textures en cartoon, en gardant la fibre « Factorio punk ».
(historique, écrit avant le ménage du repo) :
- **Simple** : filtre automatique (`tools/simple/cartoonize.py`). Jugé médiocre sur un test (taches sombres, couleurs ternes), pas affiné.
- **Complexe** : sprites refaits. Deux pistes : rendus **Blender** (fait, validé par Bastien) et génération **IA via ComfyUI** (en test).

## Fait

- Mod de base : `info.json`, `data-final-fixes.lua` (remplace les chemins listés dans `manifest.lua`), `tools/build_manifest.py`.
- Pipeline Blender (`tools/blender/`) : projection calibrée sur l'original (30°, sol raccourci, parois en tronc de pyramide), 3 tons d'ombrage, contours Freestyle, palette mesurée.
- **Assembleur 1 animé** : 32 images, cadre 214×226, calé sur l'emprise de l'original (92 % de recouvrement de silhouette). Planche installée dans `graphics/overrides/base/entity/assembling-machine-1/`.
- `STYLE.md` : guide de style complet.
- `tools/complex/comfy_batch.py` : automatise ComfyUI par son API HTTP (stdlib uniquement), avec test sur faux serveur.
- Workflow `tools/complex/workflows/sd15_canny_api.json` : SD 1.5 + ControlNet canny en img2img.
- `tools/requirements.txt` corrigé (opencv-python, numpy, Pillow, bpy).

## Résultat des essais IA (ComfyUI Desktop, Windows)

Premier essai sur l'assembleur original : **« très très moyen »** (512×512, brun, pixélisé, halos).
Causes probables :
- canny bruité, car l'entrée est un petit sprite très texturé ;
- `denoise` à 0,8 qui garde les couleurs sombres ;
- SD 1.5 de base pas orienté cartoon.

Hypothèse non vérifiée : l'IA tiendra mal la cohérence sur 32 images d'animation. Elle servirait mieux en passe de finition sur des rendus Blender.

## Non vérifié

- Le mod n'a **jamais été lancé dans Factorio**.
- La disposition de la planche (32 images, 8 par ligne) est supposée ; à confirmer dans les prototypes (`data/base/prototypes`).
- `comfy_batch.py` n'a tourné que contre un faux serveur ; un vrai ComfyUI peut demander des ajustements.
